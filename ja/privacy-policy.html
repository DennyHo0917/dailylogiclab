プライバシーポリシー

最終更新: 2026年10月2日

Daily Logic Lab は、無料のブラウザ型ロジックパズルと補助ツールを提供します。このページでは、サイト利用時に扱われる可能性のある情報を説明します。

利用者が提供する情報

遊ぶための登録やログインは不要です。任意のカード決済はStripeの決済画面で入力します。GitHub Issuesに投稿した情報はGitHubが取り扱い、公開されることがあります。

ブラウザ内の保存

連続記録、ベストタイム、解いた日、ヒント回数、最近のイベントなどがブラウザ内に保存されることがあります。ブラウザのサイトデータ削除で消せます。

解析

Daily Logic Lab は Google Analytics を使い、ページ表示、パズル開始、ヒント、チェック、一般的な端末やブラウザ情報などを集計して改善に役立てます。

応援の案内表示、ダイアログ表示、選択金額、決済画面の作成依頼、エラー、移動、アドレスのコピーも計測します。これらは操作の記録で、支払い完了を示すものではありません。言語、入口、支払い方法、金額、ネットワーク、通貨を含むことがありますが、カード情報、メールアドレス、ウォレットアドレス、取引ハッシュ、Checkout識別子はこれらのイベントに追加しません。

別途、サーバーでStripeのカード決済成功を確認し、手数料控除前の金額、通貨、仮名化した取引参照をGoogle Analyticsの購入イベントとして送信します。取得できる場合はAnalyticsのクライアントIDとセッションIDをStripeへ渡し、支払いと訪問を関連付けます。取得できない場合は決済ごとの識別子を使い、訪問には関連付けません。同じ通知は重複計上しません。カード情報、氏名、メールアドレス、Stripeの元の決済識別子をこれらの分析イベントに送ることはありません。

任意のチップと決済

カードでのチップでは、サーバーからStripeへ選択金額、画面の言語、戻り先のページを送り、一度限りの決済画面を作成します。Stripeが決済とそこで入力した連絡先を処理します。運営者はStripeの管理画面で決済記録やStripeに提供された顧客情報を確認できます。このサイトでカード番号を収集することはありません。

暗号資産はウォレットから表示された公開アドレスへ送金します。ブロックチェーン上の取引は公開され、ウォレット提供者には独自のプライバシー方針があります。このサイトで取引ハッシュを要求したり、送金を検証したりすることはありません。

外部リンク

GitHub や Google ドキュメントなど外部サイトへのリンクがあります。外部サイトのプライバシー運用は Daily Logic Lab の管理外です。

子どものプライバシー

Daily Logic Lab は一般向けパズルサイトであり、子どもの個人情報を意図して収集しません。
