Ziel

    Tippe auf eine Kante, um zwischen Unbekannt, Linie und X zu wechseln. Jede Zahl gilt exakt.

    So funktioniert das Rätsel

    Spielanleitung

    Ein Tipp setzt eine Linie, der zweite ein X, der dritte löscht die Markierung. X hilft beim Ausschließen.

    Regeln

    Jede Zahl gibt an, wie viele ihrer vier Seiten zur Linie gehören. Die fertige Linie ist geschlossen, zusammenhängend und ohne Abzweigungen.

    Tipps

    Eine 0 hat vier X-Kanten, eine 3 drei Linien. An jedem benutzten Eckpunkt treffen genau zwei Linien zusammen.

    Häufige Fragen

    Fragen zu Slitherlink

    Was bedeutet eine Zahl?

    Sie nennt genau die Anzahl der Linien an den vier Seiten dieses Feldes.

    Darf die Linie eine Abzweigung haben?

    Nein. An jedem benutzten Eckpunkt liegen am Ende genau zwei Linien.
