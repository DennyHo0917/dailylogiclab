杀手数独组合计算器

快速了解

计算器简介

用途
按笼和与格数列出符合条件的数字组合。
输入项
可以设置总和、格数、可用数字以及是否允许重复。
标准规则
普通杀手数独的同一笼内不重复数字。
使用方式
工具免费、无需注册，直接在浏览器中运行。

输入笼内总和与格数，计算器会列出所有可能的数字组合。再关闭同行、同列或同宫中已经不能使用的数字，就能进一步缩小范围。

默认设置适用于笼内数字不重复的标准杀手数独。允许重复选项则适合明确允许重复的变体、Kakuro、KenKen或其他和数谜题。

查找笼内组合

先填写笼和与格数，再把棋盘上已经排除的数字关闭。

  • 标准杀手数独请保持数字不重复。
  • 只有题目规则明确允许时才开启重复。
  • 需要对照候选时，可以复制计算结果。

唯一或强制组合

接近极值的笼和往往只有一组数字：2格和为3只能是1 + 2，和为17只能是8 + 9；4格和为10只能是1 + 2 + 3 + 4，和为30只能是6 + 7 + 8 + 9。

45法则

1到9的总和是45。完整的一行、一列或一个3×3宫中，已知笼和可以帮助反推出剩余格子的总和。

如何使用计算器

  1. 输入笼内标注的总和。
  2. 输入这个笼包含的格数。
  3. 标准杀手数独保持重复选项关闭。
  4. 关闭同行、同列、同宫或同笼中已经排除的数字。
  5. 把剩余组合与棋盘上的实际位置继续交叉排除。

示例：3格和为17

3格笼和为17且数字不重复时，共有7种基础组合：1 + 7 + 9、2 + 6 + 9、2 + 7 + 8、3 + 5 + 9、3 + 6 + 8、4 + 5 + 8、4 + 6 + 7。

计算器负责整理加法，真正的解题仍依赖数独规则。哪一组能放进笼里，要继续结合行、列、宫和每个格子的位置判断。

常见笼型

条件常见不重复组合作用
2格和为31 + 2两个数字作为一组被确定。
2格和为178 + 9高位数组合，便于在行与宫中排除。
4格和为101 + 2 + 3 + 4低和四格笼，可以排除较大数字。
4格和为306 + 7 + 8 + 9高和四格笼，可以排除较小数字。

杀手数独、Kakuro与KenKen

杀手数独把数独的行列宫规则与笼和结合起来，通常不允许同笼重复数字。Kakuro和KenKen也会用到数字组合，但是否允许重复取决于具体规则，开启选项前请先核对题目说明。

常见问题

组合计算器有什么用？

它按总和与格数列出数字组合，并允许关闭已经不能使用的数字。

应该允许重复数字吗？

标准杀手数独不允许。只有变体规则明确说明时才开启。

为什么最大总和会超过45？

这是为允许重复数字的变体准备的；不重复时1到9总和就是45。

它能解完整盘面吗？

不能。它只计算笼内组合，完整解题仍要使用行、列、宫和位置关系。
