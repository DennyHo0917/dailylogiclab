隐私政策

最后更新： 2026年10月2日

Daily Logic Lab 提供免费的浏览器逻辑谜题和解题辅助工具。本政策说明你使用网站时可能涉及的信息。

你主动提供的信息

玩谜题无需账号或登录。可选的银行卡打赏在 Stripe 托管付款页填写。如果通过 GitHub Issues 联系我们，发布的信息由 GitHub 处理，并可能公开。

浏览器本地存储

谜题体验可能在你的浏览器中保存少量数据，例如连胜、最佳时间、已完成日期、提示次数和近期浏览器内事件。你可以通过清除浏览器站点数据来删除。

分析统计

Daily Logic Lab 使用 Google Analytics 了解聚合使用情况，例如页面浏览、开始题目、使用提示、检查盘面以及一般设备或浏览器信息。

我们也统计支持提示展示、弹窗打开、金额选择、付款页创建请求、失败、跳转及收款地址复制。这些操作不代表付款成功。事件可能包含语言、入口、付款方式、金额、网络和币种；不会向这些事件加入银行卡信息、邮箱、钱包地址、交易哈希或 Checkout 会话标识。

此外，服务端会向 Stripe 核实银行卡付款成功，再向 Google Analytics 上报购买事件，包含扣手续费前的付款金额、币种和假名化的交易参考编号。如果能取得浏览器的 Analytics 客户端和会话标识，会把它们传给 Stripe，以便将付款关联到本次访问；无法取得时使用该笔付款专属的标识，不关联访问来源。重复通知不会重复计入收入。这些统计事件不发送银行卡信息、姓名、邮箱或 Stripe 原始付款标识。

可选打赏与支付

银行卡打赏时，服务端把所选金额、页面语言和返回页面发送给 Stripe，创建一次性付款页。Stripe 处理付款及用户在其页面填写的联系信息。我们可以在 Stripe 管理后台查看付款记录及用户向 Stripe 提供的客户信息；本站不收集银行卡号。

加密货币由你的钱包转入页面显示的公开收款地址。区块链交易公开可见，钱包服务商适用各自的隐私规则。本站不要求填写交易哈希，也不验证转账。

第三方链接

网站可能链接到 GitHub、Google 文档或其他外部页面。Daily Logic Lab 不负责外部网站的隐私做法。

儿童隐私

Daily Logic Lab 是面向一般用户的谜题网站，不会有意收集儿童个人信息。
