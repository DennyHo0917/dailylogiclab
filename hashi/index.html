Goal

    Click one island, then a visible island. Bridge counts cycle 0 → 1 → 2 → 0.

    Learn the puzzle

    How to play

    Select an island, then select a directly visible island in the same row or column. Repeat to cycle the bridge count.

    Rules

    Bridges run only horizontally or vertically, no pair has more than two bridges, bridges cannot cross, and all islands must connect.

    Tips

    Begin with islands whose clue is 1 or 2. A satisfied island cannot accept another bridge.

    FAQ

    Questions about Hashi

    How many bridges can connect two islands?

    A pair can have zero, one, or two bridges.

    Can a bridge pass through an island?

    No. The next visible island stops a possible bridge.
