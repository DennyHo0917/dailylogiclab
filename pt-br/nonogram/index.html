Objetivo

    Toque: Indefinida → Preenchida → X. No computador, o botão direito também alterna o X.

    Aprenda a jogar

    Como jogar

    Toque uma vez para preencher, outra para marcar X e mais uma para apagar. O controle funciona do mesmo jeito no celular.

    Regras

    Os números descrevem blocos consecutivos de casas preenchidas. Dois blocos precisam ter pelo menos uma casa vazia entre eles.

    Dicas

    Comece pelos blocos mais longos. Procure a sobreposição entre todas as posições possíveis e use os X já marcados.

    Perguntas frequentes

    Perguntas sobre Nonogramas

    O que é um Nonograma?

    É um quebra-cabeça de imagens também conhecido como Picross ou Griddlers.

    Dá para jogar no celular?

    Sim. O controle de três estados foi feito para telas sensíveis ao toque.
