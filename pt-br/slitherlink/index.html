Objetivo

    Toque em uma borda para alternar entre indefinida, linha e X. Cada número é exato.

    Aprenda a jogar

    Como jogar

    Um toque desenha uma linha, o segundo coloca um X e o terceiro apaga. Use X para descartar bordas.

    Regras

    Cada número indica quantos dos quatro lados daquela casa fazem parte do laço. No fim, a linha é contínua, fechada e sem ramificações.

    Dicas

    Um 0 tem quatro X e um 3 tem três linhas. Em cada vértice usado, exatamente duas linhas devem se encontrar.

    Perguntas frequentes

    Perguntas sobre Slitherlink

    O que cada número significa?

    É a quantidade exata de lados daquela casa que fazem parte do laço.

    O laço pode ter uma ramificação?

    Não. Cada vértice usado precisa ter exatamente duas linhas.
